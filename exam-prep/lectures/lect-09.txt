EA: Genome Structure
Naive structuring of the genome:
Pro: easy to implement, only few knowledge necessary.
Con: large search space, a lot of local maxima possible,
 may be hard or impossible to find a good solution.
Sophisticated structuring of the genome:
Pro: only legal, or good genomes are to be investigated.
Con: profound knowledge about the process and of the kind of
 possible solutions is required, can become computational
 expensive to implement inheritance and mutation.
“Normal” structuring of the genome:
Pro: still easy to implement, some knowledge necessary,
 wide variety to implement inheritance and mutation.
Con: still a lot of bad or illegal genomes possible.

The objective, is to find a placement of the 8 queens
so that they can't reach each other.
The fitness function for the EA should reflect this:
a large value of f if the placement is o.k. I
a small value of f if the placement is not o.k. O
Example: 8 Queens
A fitness function that yields a binary value (O,I)
is not a good idea for an evolutionary algorithm.
The resulting fitness surface is flat (O), with only a few
isolated peeks (I).
The value of this kind of fitness function is not reflecting,
that a genome can be close to a possible solution.

An appropriate fitness function for an EA must be shaped
accordingly;
In addition, the fitness function f value should implement, that
genomes g, close to an optimal solution should yield a larger
fitness value f(g) than those far away.
The optimal would be, to have a fitness function f(g) that is
proportional to the distance between the genome g to an
optimal genome g*.
Unfortunately this is not possible in general.

EA:
The objective, is to find a placement of the 8 queens
so that they can't reach each other.
Example: 8 Queens
A proposal for a fitness function for the 8 queens problem:
Each possibilty that one queen can attack another queen is
counted as -1
The fitness value f(g) is the sum of all attack possibilities.
This yields a graded response as required,
with a maximal value f(g*) = 0.0 when no attack is possible.
Caution:
This fitness function is only appropriate if the number of queens
is fixed to 8 (0 queens => 0 attack possibilities)

EA:
Sometimes, the combination of selection and inheritance is
producing a so called: Super-Individual.
The fitness values throughout the population will typically vary.
In the case, that one individual has a considerably larger fitness
than all other individuals, it can happen that this individual is
selected more often
(e.g. fitness proportional selection, m << l , …).
Thus, it will produce more offspring than other individuals,
increasing the number of individuals with a high fitness;
which is explicitly intended by the principle of inheritance.

should be avoided to maintain the necessary diversity within
the population (EAs are multi hypothesis approaches).
The detection of a super-individual can be really hard.
A hint for the occurrence is a shrinking variance of fitness
values in the parent population.
A close investigation of the performance graph is helpful.

EA:
An alternative scheme to operate the evolutionary algorithm
is to separate parent selection from external selection.
Then, within external selection, the m individuals to survive,
are selected from the complete population of P individuals,
and l individuals are discarded .
And, within parent selection the parents are selected from
the complete population as well, building the pool of parents
for subsequent inheritance.
The inheritance step generates l new individuals, from the
pool of parents; the pool of parents is erased afterwards.
The Next Generation is build by combining the m survivors
with the l offspring (m + l = P).

Another common way to shape the parent selection, is
called tournament selection.
Some individuals are taken randomly from the population,
and compared pairwise (randomly chosen) in a form of
tournament, the winner of each tournament is now eligible
for the pool of parents.
To further increase the fitness of the pool of parents, the
winning individuals can now undergo further stages of
tournaments among each other.
Easy to implement, easy to control the selection pressure.

Parent Selection
Another common way to shape the parent selection, is
called tournament selection.
Some individuals are taken randomly from the population,
and compared pairwise (randomly chosen) in a form of
tournament, the winner of each tournament is now eligible
for the pool of parents.
To further increase the fitness of the pool of parents, the
winning individuals can now undergo further stages of
tournaments among each other.
Easy to implement, easy to control the selection pressure.

A probabilistic parent selection, depending on the reached
fitness values f(g) is a common way to implement this.
It showed to be feasible to make up the set of parents with
those individuals, that have shown a good fitness f(g),
and explicitly include additional individuals that have not
performed as good.
Common probabilistic, fitness based parent selection:
- Wheel of Fortune, (Roulette-Wheel Selection)
- Boltzmann Selection, Softmax-Selection
- Tournament selection

EA: Genetic & Evolutionary Programming
© Nils Goerke, University Bonn, 6/2026 139
Artificial Life [MA-INF 4201], 09, Evolutionary Algorithms 3, Mon 15.6.26, Computer Science, University of Bonn
Although proposed as an alternative approach to “normal
computer programming”, the subject of Genetic or
Evolutionary Programming refers to EA applications where
the genome is regarded as a sequence of commands (a
program).
The fitness f(g) of the genome g is the quality the program
achieves within the given application.
The basis for genetic programming is typically not the source
code level, but a genome that is representing a formal
description of the code (syntax graph, prefix notation of
functions, …).

the fitness for the other population, and vice versa.
The population is not evaluated against a static fitness
function, but against a changing other population.
The performance of one population is the fitness for the
others population.
