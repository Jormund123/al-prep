Assignment 72 (4 Points)

of N = 8 discrete sensory distance values S = (s1, ..., s8), to a set of 2 discrete motor values
denoted with M = (ml, mr).

respect to the task of obstacle avoiding movements.
Don’t forget to define the objective and/or fitness function.
Programming Assignment: G (5 Points, due date Mon 28.6.2026)
Write a small robot simulator in Python .
The world of the robot is a rectangular world of 50x50 grid-cells. Each grid-cell is either
0 =free space, or 1 =wall. The grid-world shall be read in from an ASCII-file where the posi-
tions of all occupied cells can be found as one (X, Y )-position per line PA-G-SS26-4201.txt;
the first line of this file contains a comment, and can be omitted.
You can visualize the world with the following command within gnuplot:
plot ’PA-G-SS26-4201.txt’ using 1:2 with points
The robot has a size of 1 cell, it has a position (X, Y ) within the world and an orientation a
pointing to one of the eight surrounding cells. The robot can sense the situation of the eight
surrounding cells, and in one simulation step can move one cell into the heading a.
Implement either a wall following or a Braitenberg type 3b behaviour.
Start your robot at position (48, 17) heading south, and calculate the resulting movements
for at least 200 steps.
It is not intended to programm a visual output.
To document the movement of the robot it is suﬃcient to print out the pose (X, Y, a) of the
robot in every timestep into a file named PA-G-robot.path.
A gnuplot readable format would be; one pose per line, values separated by blanks, in the
order X Y a
The following gnuplot command could then visualize the world and the journey of the robot:
plot ’PA-G-SS26-4201.txt’ u 1:2 w p, ’PA-G-robot.path’ u 1:2 w p
Other implementations for visualization are welcome but not requested.
